
Проект представляет собой сквозной конвейер данных (Data Pipeline), разделенный на три логических модуля:
1. **Препроцессинг и нормализация (`vr_pipeline.py`):** Модуль считывает сырые логи в формате JSON Lines, парсит вложенные строковые массивы позы головы и рук, извлекая полную анатомическую структуру скелета (по 26 суставов на каждую кисть). На этапе парсинга решена проблема региональных стандартов (замена запятых на точки в десятичных дробях) и заполнена скрытая зона неактивности датчиков (интерполяция NaN нулями), что делает датасет безопасным для обучения моделей ИИ.
2. **Синхронный плеер (`sync_player.py`):** Интерактивное веб-приложение на базе **Streamlit** и **Plotly**. Модуль выводит видеозапись `.mp4` и 3D-облако точек суставов на один дашборд с единым таймлайном для валидации данных человеком.



##Инструкция по запуску

```bash
# 1. Склонируйте репозиторий и перейдите в папку проекта
cd vr-motion-data-pipeline

# 2. Установите необходимые зависимости
pip install -r requirements.txt

# 3. Запустите интерактивный синхронный плеер
python3 -m streamlit run sync_player.py
```
